# 📖 Project Overview

> [!IMPORTANT]  
> **COTATO Rrecruitment Platform**은 매 기수 반복되는 리크루팅 업무의 비효율을 개선하고,  
> 지원자에게 최적화된 지원 경험을 제공하기 위해 설계된 코테이토 전용 지원 관리 시스템입니다

**코테이토 리크루트 플랫폼**은 사용자 경험과 운영 프로세스를 함께 고려한 설계를 통해 운영진의 부담을 줄이고<br>
보다 효율적인 리크루팅 환경을 구축하는 데 집중했습니다.
